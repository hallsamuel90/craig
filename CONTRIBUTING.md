# Contributing

Craig is open source, but it is not currently a community-maintained project.

Use the channels that best fit what you need:

- File a [bug report](https://github.com/hallsamuel90/craig/issues/new?template=bug_report.yml) for reproducible bugs and installation problems.
- Use [Q&A](https://github.com/hallsamuel90/craig/discussions/categories/q-a) for focused usage and configuration questions.
- Share feature suggestions in [Ideas](https://github.com/hallsamuel90/craig/discussions/categories/ideas).

Bug reports should include your operating system, Node version, Craig version, relevant command output, and a minimal reproduction when possible.

Pull requests are not generally accepted unless they were discussed with the maintainer first. Unsolicited PRs may be closed without review so the project can stay aligned with the maintainer's roadmap and release process.

Do not include private `.craig/` state, task prompts, terminal logs, local workspace paths, API tokens, or repository secrets in issues or attachments.

All participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
